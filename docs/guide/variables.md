# 变量与采样

实时采样变量，查看指针、枚举和同名变量，筛选变量来源。

## 实时采样与历史

在目标运行时持续读取 RAM 中的变量，把数值显示在侧栏和波形窗口中。点击 **开始** 后所有查看对象一起采样，再次点击则全部停止。

### 采样频率

| 查看位置 | 目标频率 | 是否保存历史 |
| --- | --- | --- |
| 波形窗口中的变量，包括隐藏的曲线 | 0.1–200 Hz，默认 30 Hz，或不限速 | 是 |
| 只在侧栏查看或写入的变量 | 固定 20 Hz | 否，只显示当前值 |

在波形窗口工具栏输入频率，或用输入框内的下拉滑条选择 20、50、100、200 Hz。默认频率由 `emberprobe.sampleFrequencyHz` 设置。

实际频率取决于探针吞吐、变量数量和地址分布，可能低于目标值。调试时不限速不生效：启动调试时采样暂停，目标运行后按设定频率恢复；目标暂停时不连续采样，每次停下读取一份当前值。

想获得更高的实际频率，可以：

- 减少查看的变量，或让它们集中在相邻地址；
- 提高采样链路时钟 `emberprobe.samplingAdapterSpeedKhz`；
- 使用内置 OpenOCD，也就是让 `emberprobe.openocdPath` 保持默认值 `openocd`（Windows 和 Linux x64）。

侧栏查看列表中的结构体、数组和运行时对象只在展开时采样，折叠后不再读取，其中的变量也一起停止；再次展开后恢复。全部折叠时探针保持连接，提示展开变量。波形窗口按自己的列表采样，不受侧栏折叠影响。

### 不限速

把滑条拖到最右端选择 **不限速**，输入框显示 `-`，工具栏显示实际频率。上一轮读取完成后立即开始下一轮，速度由探针决定。选择任一频率挡位或输入数值即可退出，选择结果按工作区保存。

使用前请注意：

- 只在独立采样时生效。调试会话中按最近一次设置的有限频率采样，输入框提示会说明原因。
- 侧栏变量仍保持 20 Hz。
- 高频采样会更快消耗内存和磁盘归档。
- Agent 无法开启不限速，只能设置有限的采样间隔。

### 隐藏曲线与成员

隐藏曲线只影响绘图，变量继续采样和记录。重新显示时可以看到隐藏期间的历史。

把静态结构体等复合变量加入波形窗口后，它的标量成员会立即开始记录。之后再打开某个成员的曲线，就能看到从父变量开始采样以来的历史。

移除变量后停止采样，但已记录的数据仍可以导出。

### 查看历史

时间轴和“全部”窗口覆盖从开始采样或上次清空历史以来的整段会话。最近的数据在内存中，更早的数据从磁盘读取，无需手动切换。放大较早的时间段时，曲线可能短暂显示为较粗的概览。

- **冻结图表**：固定当前历史用于查看，后台继续采样和更新当前值。冻结后新加入的变量在恢复实时后才会显示。
- **清空历史**：只清空当前窗口当前会话的历史，不影响其他窗口。
- 修改变量的观察类型后，该曲线的实时历史会重新开始。

### 导出 CSV

点击 **导出 CSV**，选择变量和时间范围。默认导出所选变量从开始采样或上次清空历史以来的全部原始采样点，也包括超出内存范围的历史和已移除变量的数据。

- 只导出波形窗口的变量，只在侧栏查看的变量不会写入 CSV。
- 冻结不改变导出范围；进制、归一化和曲线样式也不影响 CSV。
- 导出时可在 VS Code 通知中查看进度或取消，完成后可以在文件夹中显示。
- 如果保存对话框打开期间清空了历史或切换了会话，导出会取消，避免导出错误的数据。

### 历史容量

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| `emberprobe.chartHistoryMaxMiB` | 512 MiB（64–4096） | 最近历史占用的内存上限 |
| `emberprobe.samplingArchiveMaxMiB` | 1024 MiB | 临时磁盘归档上限 |

内存预算不足只会缩短内存中保留的范围，更早的数据仍从磁盘读取，采样不会停止。

**磁盘归档在扩展退出后删除**，需要保留的数据请先导出 CSV。

### 常见问题

**采样自动暂停了。** 磁盘归档已满或写入失败。先导出需要的数据，然后清空历史，或调大 `emberprobe.samplingArchiveMaxMiB`、检查磁盘剩余空间。

**实际频率远低于目标频率。** 这通常是探针或 SWD 时钟的上限，无线探针和 HID 探针尤其明显。参考上文提高频率的方法。

**工具栏提示受扩展宿主限制。** VS Code 正在执行其他繁重任务，例如其他扩展的配置或解析。任务结束后会恢复。

**调试时选了不限速却没有生效。** 这是预期行为，不限速只在独立采样时生效。

**图表提示历史不完整。** 这段数据在内存和磁盘中都不存在，通常是磁盘写入失败或归档已满造成的。

## 指针与 C++ 成员

使用含调试信息的 ELF 时，侧栏和波形窗口会显示指针指向什么，并默认隐藏编译器和标准库的内部成员。

### 查看结构体和类

默认只显示你声明的成员。隐藏的是编译器生成的成员（如 `_vptr.Base`）和标准库的内部成员（如 `_M_*`）。`std::pair::first` 这样的公开成员仍然显示。

常见的库类型直接显示为一行：

| 类型 | 显示 |
| --- | --- |
| `std::atomic<T>` | 存储的值 |
| `std::array<T, N>` | 各元素 |
| `std::chrono::duration`、`time_point` | 计数值 |
| `std::unique_ptr`、`shared_ptr`、`weak_ptr` | 管理的指针 |
| `std::function` | `empty`，或调用目标的地址和符号 |

有隐藏成员时显示“已隐藏 N 个内部成员”。点 **显示原始成员** 可以看全部字段，这个开关按变量保存。隐藏只影响显示，不影响波形、CSV 和写入。

### 查看指针

值的位置显示指针的目标，悬停看地址，点击复制地址：

| 指向 | 显示 |
| --- | --- |
| 变量、数组元素 | `&g_widgets[1]` |
| 结构体成员 | `&g_widgets[2].y`、`&grid[1][2]` |
| 变量内部的偏移 | `&rxBuf+0x3` |
| 函数 | `clickHandler()`，函数内部显示 `name+0x4` |
| 虚表 | 动态类名 |
| 只读字符串 | `"hello"`，最多 64 字节 |
| 外设寄存器 | `&GPIOA->ODR`，需要绑定 SVD |
| 无符号的 Flash、RAM 等区域 | `0x20001234`，悬停显示区域 |
| 所有已知区域之外 | 警告色的 `0x12345678` |
| 零 | `NULL` |

RAM 中的字符串要展开指针才能看到。

### 展开指针

点击数据指针左侧的箭头，指向的对象会显示在下方。只有展开时才读取目标内存，收起后停止读取。也可以直接输入 `owner.value`、`owner->field` 或 `owner.value.field`。

- 每次展开一层，目标内的指针有自己的箭头。
- 指针变化时目标跟随变化，指针为 `NULL` 时箭头隐藏。
- 目标类型按指针声明的类型，不判断实际的派生类。
- `char` 指针显示最多 32 字节的字符串预览。
- `void *`、函数指针和只有声明的类型不能展开。
- 展开的目标只读，界面和 Agent 都不能写入。
- 只能读取 ELF 中已确认的内存范围，不读外设寄存器区域，读不到时显示不可用。

指针变量加入采样列表后，曲线默认隐藏，因为地址本身很少有意义。打开过的曲线会被记住。

重新打开窗口时，指针显示上次采样的目标，字体变淡并倾斜，悬停显示“上次采样”。这只是提示，开始采样后才读取目标。

### 限制

- 以上功能需要 ELF 含 DWARF 调试信息。
- 内置 GDB 调试器的变量视图不受影响。

## 枚举变量

使用含调试信息的 ELF 时，EmberProbe 自动读取 C/C++ 枚举类型，把枚举变量显示为成员名加数值，无需配置。

### 显示方式

| 情况 | 显示 |
| --- | --- |
| 普通枚举 | `ERROR(-1)` |
| 带作用域的成员，如 `app::State::Active` | `.Active(3)`，`::` 前缀用一个点代替 |
| 多个成员同值 | `ACTIVE / READY(3)` |
| 值不在枚举表中 | 只显示数值 |

结构体成员、数组元素和类型别名中的枚举同样支持。

### 限制

- 波形和 CSV 保存数值，不保存名称。
- 写入时输入数值，成员名只用于显示。
- `int value = ACTIVE` 这样的变量是整数，显示数值，因为调试信息里它的类型不是枚举。
- 缺少足够类型信息的枚举显示为不可用，不会按猜测的类型读取；推断出的类型只读。
- 超过 1024 个成员或名称文本过大的枚举表不会加载。

## 同名变量

不同源文件里的 `static` 变量或匿名命名空间变量可以同名。EmberProbe 保留每一个，并显示它们来自哪个文件，这是正常情况，不会警告。

### 查看

可用变量列表、波形导入列表和输入补全优先显示可读名称，同名项旁边用淡色显示来源文件。文件名也相同时显示最短能区分的路径。悬停可以看完整名称、源路径和地址。

### 添加到波形

在波形窗口输入 `g_localConfig` 并按 Enter。匹配多个变量时，输入框下方列出来源候选：

- 点击候选，或用方向键选中后按 Enter，才会添加。
- 没有默认项，不会自动选择。
- 按 Escape 或编辑输入可以取消。

也可以直接写明来源：

```text
probe_lab.cpp::g_localConfig
'path/to/probe_lab.cpp'::g_localConfig
```

### Agent

名称有歧义时，Agent 读写会收到 `VARIABLE_AMBIGUOUS` 和候选列表，必须明确指定目标。

### 限制

ELF 缺少调试名称时显示链接符号名。

## 变量来源筛选

ELF 里的变量很多来自 HAL、RTOS 和库。侧栏“ELF 全部变量”右上角的 **仅用户** 按钮把它们隐藏，只留下你的代码定义的变量。

### 使用

点击按钮切换。关闭后恢复完整列表。

- 筛选只影响列表显示，不影响读写和采样。
- 已加入查看或写入列表的变量不会被移除。
- 悬停变量名可以看到分类和源文件。
- 判断不了的变量一律保留。

### 隐藏哪些变量

| 分类 | 例子 |
| --- | --- |
| 工具链和运行库 | newlib、libgcc、libstdc++ 的变量 |
| RTOS | FreeRTOS、ThreadX、RT-Thread、Zephyr，以及 `pxCurrentTCB`、`ucHeap` |
| 中间件 | `Middlewares`、`Third_Party`、USB、FATFS、LWIP、LVGL |
| 厂商代码 | CMSIS、HAL 驱动，`SystemCoreClock`、`uwTick`，CubeMX 外设句柄如 `huart1` |

### 限制

- `main.c`、`freertos.c` 同时有生成代码和 `USER CODE` 段。生成的句柄和 RTOS 对象会被隐藏，你写的普通变量会保留。
- `USB_DEVICE/App`、`FATFS/App` 等目录下的文件也有 `USER CODE` 段，里面的变量会随中间件一起隐藏。需要时关闭筛选。
- `Drivers/BSP` 等板级代码不会被隐藏。
- 没有调试信息的 ELF 只能按名称判断，准确度较低。
