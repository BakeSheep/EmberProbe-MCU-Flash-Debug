# 波形

使用波形窗口、调整曲线显示、设置背景图标。

## 波形窗口

波形窗口用曲线显示变量随时间的变化。工具栏和图表操作见[使用教程](../../README.md#5-波形图)，采样频率和历史见[实时采样与历史](variables.md#实时采样与历史)。

### 多个波形窗口

可以同时打开多个波形窗口，每个窗口有独立的变量列表、曲线显隐和历史。重启 VS Code 后，窗口会恢复各自的内容；编号变化只影响标题。

关闭窗口后，它的编号会释放给新窗口。

旧版本保存的窗口升级后也会恢复。如果两个窗口的数据归属冲突，其中一个会得到独立的变量列表副本，历史互不影响。无法识别归属的旧窗口以空列表打开，工作区里原有的变量列表仍然保留。

### 缩放与纵轴适配

滚轮以鼠标位置为中心缩放：绘图区同时调整 X/Y 轴，底部坐标轴只调整时间范围，左侧坐标轴只调整 Y 轴。左键拖动平移，中键拖动只调整时间范围；纯水平拖动不会关闭自动 Y 轴，轻微指针抖动不会改变视图。

时间轴右侧的 **纵轴适配** 支持左／右键短按和长按。按住约半秒触发长按，松开后不会再触发短按；按住时拖动离开可取消尚未触发的操作。点击旁边的上拉箭头，也可以选择同样的四项：

| 模式 | 快捷操作 | 行为 |
| --- | --- | --- |
| 单次居中留白 | 左键短按 | 当前可见曲线收至中央两格，上下留白，随后保持纵轴范围 |
| 单次纵轴适配 | 左键长按 | 当前可见曲线铺开，上下保留少量空间，随后保持纵轴范围 |
| 自动居中留白 | 右键短按 | 持续居中留白 |
| 自动纵轴适配 | 右键长按 | 持续按可见曲线调整纵轴范围 |

聚焦主按钮后，Enter 或空格执行单次居中；按 ↑ 或 ↓ 打开上拉菜单。菜单内可用方向键选择，Esc 关闭并返回箭头按钮。鼠标停在主按钮上，可以查看当前纵轴模式和四种快捷操作。

适配只使用当前时间窗口内已显示曲线的数据，包含临时增益，不修改原始记录、时间窗口或冻结状态。常量曲线会保留非零范围；无数据时保留当前范围。归一化模式按其 0～1 标尺适配，与原始数值模式分别保留纵轴状态。

自动模式在新极值超出范围时立即扩张，在空间明显富余并持续约一秒后收缩，避免频繁跳动；显示尚未稳定时，曲线可能暂时小于目标高度。手动缩放或竖向平移 Y 轴会退出自动模式，可用右键快捷操作或上拉菜单重新开启。左键快捷操作或菜单中的单次适配也会切换为手动范围。状态区分别显示跟随、历史或冻结状态，以及纵轴是否自动调整。

点击 **恢复上一视图** 可以撤销最近的平移、滚轮缩放、时间范围选择或纵轴适配，最多保留 20 步。连续滚轮操作合并为一步。聚焦图表后也可按 Ctrl+Z（macOS 为 Command+Z）。切换归一化、冻结／恢复实时或清空历史后，撤销记录会清除；关闭窗口后不保存。

放大后，时间刻度自动显示毫秒；两个有效采样点之间的连续线段仍可查看，但不会将插值计为新的采样点，也不会跨缺失数据连线。

### 修改单个变量的显示

右键点击变量行，或在行上按 Shift+F10，可以修改类型、进制、颜色和线型。按 Esc 或点击外部关闭菜单。

- **进制**：DEC、HEX、BIN 只影响当前窗口中该变量的显示值和悬停读数，移除变量后清除。
- 小数按数值换算，例如 `1.5` 显示为 `0x1.8` 或 `0b1.1`；64 位整数保持精确。
- 枚举在 HEX 和 BIN 下显示数值，在 DEC 下保留名称。指针保留目标名称。
- 进制不改变采样、曲线位置、共享的曲线样式和 CSV 导出。
- 复合变量行没有进制选项。

### 临时增益

右键数值变量，在“增益”框输入倍数，或用 `−` / `+` 按 0.1 调整。默认是 1，可以用小数、0 和负数。

- 只影响当前波形窗口的数值、曲线和悬浮读数。
- 采样记录、冻结数据和 CSV 保留原始值。
- 负数翻转曲线，0 得到水平线，手动设置的 Y 轴范围不变。
- 增益不是 1 时不显示枚举名称，很大的整数可能被舍入。
- 关闭波形窗口、重载或退出 IDE 后恢复为 1；移除变量时一并清除。

指针地址、字符串和复合对象没有增益。

### 曲线颜色和线型

第一次打开一条曲线时，它会自动获得一种样式。优先使用未占用的实线，再使用虚线和点线，共有 144 种预设组合，用完后继续生成新颜色。

- 导入结构体、展开成员、查看隐藏变量都不会占用样式；从未显示过的变量以灰色预览。
- 隐藏曲线会保留它的样式，重新显示时不变；移除变量后释放。
- 自动样式只在当前窗口内分配。
- 右键菜单里直接点实线、虚线或点线切换线型。
- 在右键菜单中手动选择的颜色和线型保存在工作区，并在多个窗口间共享。

## 波形图背景图标

在波形图网格和曲线下方显示一个淡色图标，比如团队或项目的标志。

### 设置图标

1. 打开 VS Code 设置（Ctrl+,），搜索 `@ext:BakeSheep.emberprobe background`。
2. 在 **Chart Background Icon: Enabled** 中点击 **导入/更换 PNG**，选择图片。

也可以在命令面板运行 `EmberProbe: 导入/更换波形背景图标`。波形图内的设置菜单不提供导入入口。导入时如果没有打开波形窗口，会自动打开一个用于预览。

- 取消勾选：暂时隐藏图标，下次勾选时恢复。
- 点击 **移除背景图标**，或运行 `EmberProbe: 移除波形背景图标`：删除已保存的图形。

### 图片要求

- PNG 文件不超过 4 MiB，任一边不超过 4096 像素，总计不超过 1600 万像素。
- 透明底图片保留原有的透明度，这是最可靠的方式。
- 纯色底图片会自动去除与边缘相连的背景。不与边缘相连的区域会作为图形保留。
- 背景复杂的图片无法可靠抠图，请先准备透明底 PNG。

图形以主题前景色、6% 透明度显示在图表中央，保持比例，宽高不超过绘图区的 60%，图表为空时也会显示。

### 保存范围

- 处理在本地完成，只保存去色后的图形轮廓，不保存原图、颜色或文件路径，也不上传。
- 在本机当前 VS Code 用户配置的所有项目中共享，不参与 Settings Sync。
- 同一窗口内的波形图立即更新；其他 VS Code 窗口在重新获得焦点或打开波形图时刷新。

导入失败时原背景保持不变，比如图片无法读取、抠图结果为空或保存失败。
