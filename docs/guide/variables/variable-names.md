# 同名变量与来源选择

不同源文件中的 C `static` 或 C++ 匿名命名空间变量可以合法同名。EmberProbe 保留每个变量，并按编译单元给出唯一身份；正常加载 ELF 时不会因此显示警告。

侧栏可用变量、波形导入列表和输入补全优先显示 DWARF 中的可读名称。同名项旁以弱化文字显示来源文件；文件 basename 相同时使用最短唯一的路径后缀。悬停查看完整限定名、源路径和地址。ELF 缺少可读调试名称时保留链接符号名，不猜测变量身份。

在波形窗口输入裸名（如 `g_localConfig`）并按 Enter，如果匹配多个变量，输入框下会展开来源候选，保留原输入。点击候选，或用上下方向键选中后按 Enter，才会添加对应变量。没有默认候选。Escape、编辑输入或重新加载 ELF 会取消旧请求，迟到的响应不会添加变量。

也可以直接输入 `probe_lab.cpp::g_localConfig` 或 `'path/to/probe_lab.cpp'::g_localConfig`。内部观察项、采样和写入继续保存完整的符号身份。Agent 读写仍对有歧义的裸名返回 `VARIABLE_AMBIGUOUS` 及结构化候选，必须明确指定目标；界面不会自动改选另一份变量。

真实的 ELF/DWARF 解析错误、预算超限和无法唯一确认的身份仍保留诊断。显式同名诊断和歧义说明优先使用已解析的可读名称，结构化候选保留链接符号身份供程序调用。

ELF/DWARF 诊断说明随界面所选语言显示为中文或英文，切换语言时已有提示会立即更新。诊断代码、文件名、路径和数值保留原值。原始解析消息继续保存在日志与接口结果中；现有诊断位置和显示时机不变。
