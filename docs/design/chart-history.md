# 波形历史与归档设计

用户行为见[实时采样与历史](../guide/variables.md#实时采样与历史)，读取与调度见[采样链路设计](sampling-pipeline.md)。

## 消费者分层

| 消费者                               | 目标频率            | 原始历史                            | 绘图                       |
| ------------------------------------ | ------------------- | ----------------------------------- | -------------------------- |
| 波形窗口观察变量（含已选择标量成员） | 用户设置 0.1–200 Hz | 最近 30 分钟内存历史 + 完整磁盘归档 | 仅计算可见曲线             |
| 波形窗口静默变量                     | 同上                | 同上                                | 重新开启时读取当前视口历史 |
| 仅侧栏观察或写入卡片                 | 20 Hz，负载高时降低 | 无                                  | 当前值                     |

独立限速采样优先完成到期的波形读取。若侧栏仅含独占静态寻址变量且在波形周期有空档时测得可合并耗时，则直接并入约 20 Hz 到期的波形读取周期（复用同一次 Tcl/USB 往返并按满 200 Hz 不丢槽）；含独占运行时对象或合并耗时会挤占波形周期的侧栏仍退回独立读取：按最近至多 8 次读取耗时的 75 分位加 0.5 ms 判断是否能放进波形空档，未知耗时在首个可用空档测量，超出空档时按约 10% 探针时间占比将最大刷新间隔限制在 50–200 ms（保底 5 Hz），达到上限时在下一次可用时隙刷新。独立侧栏轻微越过波形边界但当前槽位仍留足下一次波形耗时与余量时保槽继续，仅在预算不足时跳过整槽并保持原相位。FIFO 仍负责探针事务仲裁。

侧栏专属变量每个刷新周期都重新读取；即使同时存在侧栏专属变量，与波形共享的变量仍在波形周期内按 20 Hz 直接交付侧栏（保留原始采集时间），独立侧栏轮次可复用 50 ms 内的波形读数。速率计入有效的新读数，场景中同时有共享和专属变量时，侧栏速率来自专属变量。样本携带消费者归属与采集时间，波形归档接收波形消费者的样本。不限速与调试模式在两组到期时合并读取，调试采样用 P95 / 40% 预算，暂停目标后的 DAP 快照间隔至少 250 ms。

Tcl 无回显自测、读取计划和回退由采样链路负责。历史层只接收已经解码的样本及其消费者、时间和会话身份。详见[采样链路设计](sampling-pipeline.md#tcl-响应与合并读取)。

## 历史与导出

Agent 在没有打开波形窗口时启动持续采样，默认窗口的查看列表仍参与读取计划，数据直接写入该窗口的磁盘归档。波形窗口关闭或尚未打开时无需为它保留 Worker 的近期曲线缓存。宿主按历史范围保存每条曲线的观察起点，重开窗口时仍用相同的变量身份和起点查询归档。

每轮采样的全部样本共用一个与 epoch 对齐的亚毫秒时间，取本轮首次读取前到末次读取后的中点；周期互不重叠，同一通道时间严格递增，侧栏复用保留原时间，调试守卫仍用 `Date.now()`。Worker 历史、Float64 归档、图表传输及 CSV 保留小数毫秒，每轮仍为一行归档/CSV；整毫秒时间的 CSV 文本不变，亚毫秒时间多输出 3 位微秒。

隐藏仅控制绘图，继续采样、记录及更新当前值（最多 20 Hz）。重新显示保持已有缩放与时间窗口；“全部”、时间轴、平移缩放及粗略底图使用当前窗口全部观察变量从采样开始或上次清空以来的完整会话边界。移除变量停止采样，已记录数据仍能从完整归档导出。改观察类型重置该曲线的实时历史，完整归档按类型分别保留。

静态复合变量（例如 `app::g_pid`）加入波形窗口后，整块读取中的可观察标量成员立即作为静默通道记录，无需先点击成员绘图。稍后开启成员可恢复从父变量开始采样以来的保留历史，冻结及 CSV 同样包含这些成员。父变量与单独选择的同一成员每批只记录一次，不增加静默成员的硬件读取；移除父变量释放其隐式历史，单独保留的成员继续记录。运行时对象仍遵守现有成员选择、寻址及读取预算规则。

历史 Worker 每块最多保存 4096 点，尾块从 64 点开始按需倍增：Float64 时间、Float64 数值、Uint8 缺失标记，非 Number 等价的精确文本另存。按最新采集时间保留 30 分钟，每通道上限 360,001 点；降低采样率不删除窗口内的旧高频点。暂停期间不进行时间淘汰。

`emberprobe.chartHistoryMaxMiB` 默认 512 MiB，范围 64–4096 MiB。预算按实际分配容量计算，包含被冻结或导出引用保留的缓冲块。先释放过期块，再通过增量堆索引优先淘汰近 5 秒采集时间内未被实时视口请求的通道块，同类按最旧块优先；触及预算时尽量释放 5% 余量，缩短内存保留范围；仍不足时整批跳过内存写入。历史 Worker 队列背压也整批丢弃内存批次并标记断点，均不停止或暂停采样与磁盘归档。内存淘汰或队列跳过不再缩短可查看范围，旧数据由归档补齐；`limited` 仅表示内存与归档均无法提供的数据（例如磁盘失败或归档容量耗尽），每次采样启动或清空后最多提示一次。释放快照、减少观察变量或调整预算后可继续保留新样本；新开启且内存历史已淘汰的曲线会通过归档恢复路径重建。历史 Worker 真正故障时自动重启并从磁盘归档重建当前窗口、会话及清空代次的最近 30 分钟；每次采样启动或清空后最多重试 3 次，单次最多 30 秒，只有恢复失败才报告本地化错误。重建同样遵守内存预算；恢复期间归档继续写入，暂停内存追加以避免恢复被并发修改取消，随后做一次增量追赶，尚未追上的样本保留断点提示。磁盘归档容量及扩展退出清理策略保持原有配置；磁盘故障或容量耗尽也会暂停采样。

冻结通过引用固定后台历史范围，包含已有静默变量。采样与当前值继续更新，冻结后开启静默曲线查看冻结历史，新变量恢复实时后显示。清空取消待发当前值、视口请求和冻结快照，重置当前窗口/会话的归档代次；其他窗口不受影响。

磁盘归档使用 `samples.bin` 二进制记录日志，替代 NDJSON。16 字节 `EPSA` 文件头标记小端版本 1；带长度的 scope、通道定义先于样本记录，通道按变量键与身份对分配编号。每行保存 scope 编号、清空代次、Float64 时间和通道值；仅在还原文本完全一致时使用 i32/f32/f64，否则保留 UTF-8 文本，缺失值独立标记。`-0`、精确 64 位整数和枚举文本保持原样。稳定字典下，1 / 3 / 10 个 f32 通道分别约 28 / 42 / 91 字节/行，文件头与字典另计；磁盘预算包含全部二进制字节。未知记录按长度跳过，截断或损坏尾部停在最后一个完整记录边界。

归档写入时每约 64 KiB 建立一个带时间最小/最大值的内存索引块。恢复携带字典快照，从首个可能覆盖最近 30 分钟的块开始读取；仍按 scope、清空代次、观察起点和通道身份过滤，并从前次完整 cutoff 边界增量追赶。索引允许时间交错，不改变内存历史保留规则。`samplingArchiveFormat.decodeRecords(buffer, offset, dictionary)` 返回 `{ rows, end, dictionary }`，其中 offset/end 是缓冲区内的字节边界；`readArchive` 以大块流式读取并在迭代结束结果中报告有效 end。

导出流式读取完整二进制采样归档。默认导出所选变量自采样开始或上次清空以来的全部原始点，包括已超出内存保留范围或已从列表移除的变量。可选最近区间或自定义范围，冻结视图及图表像素缩减均不改变导出来源。侧栏独有变量不产生归档记录。

CSV 保留字段规则、BOM、CRLF、行数与非空行统计。缺失的 `__proto__` 列按空格子输出。解析按 4 MiB 分块，使用无分配扫描器，有限数值跳过逐格转义检查，时间文本按秒缓存，输出约每 1 MiB 写入一次。

导出先写同目录 `<目标>.csv.part`，完成后原子改名。已有同名临时文件只有在是普通文件且以 CSV 表头开头时才可替换，否则写入 `<目标>.csv.<随机>.part`。取消时删除本次临时文件。VS Code 通知与波形窗口同步进度，完成通知可打开目标文件夹。保存对话框期间清空历史或切换会话会取消旧请求。Agent 的归档 CSV 请求使用相同的数据来源。

## 完整会话视口

归档满额时，清空记录的旧代次会被压缩掉。宿主暂停样本交付并等待读取结束，Worker 流式复制保留的记录到新文件，按旧截点对应的新偏移重建其他范围的冻结快照，索引完整后才交换文件。新文件同步落盘前，原归档仍是数据源。容量检查在提交编码字典前完成，避免被拒绝的行留下文件中没有定义的 ID。

30 分钟 / 360,001 点只限制近期内存缓存，不再限制后台历史模式的查看范围。Worker 只读跟踪
`samples.bin`：宿主在每次写入批次完成后通知有效字节数，常规通知最多每秒 4 次，启动、重启和清空时立即同步。
Worker 从文件头自行重建字典，仅索引完整记录，重启后重新索引整个文件；原有最近 30 分钟恢复路径继续用于填充内存。

每个 scope、清空代次、通道键和身份分别保存多级摘要。L0 每桶 256 点，L1 每桶 4096 点，L2 每桶 65,536 点，
更高层继续以 16 倍聚合；类型化数组按需增长，保留首尾、极值及其时间、计数、缺失/精确文本/时间乱序标记和行字节范围。
索引预算独立于原始内存，为 `chartHistoryMaxMiB` 的 25%（默认 128 MiB）；压力下先回收已清空代次，再丢弃最旧 L0 页，
极长会话继续保留更高层摘要。多通道尾页占用过大时也可退到父层，后续样本仍更新父层；固定快照保留其代次。
索引降级会使旧图更粗，不设置 `limited`。状态另报 `indexBytes`、`indexMaxBytes`、`rawCacheBytes`
及 `indexedOffset`，近期原始缓存仍报原有 `bytes` / `maxBytes`。

完整会话底图和长视口选择时间跨度不超过一列的最粗摘要层，在同一像素网格聚合。放大到 L0 仍过粗时，按桶的字节范围
读取原始行并缩减，每请求最多读取 16 MiB，超出部分使用可用摘要；解码行另有 8 MiB 的 LRU 缓存。缺失桶在粗略显示时
保守断开，不能跨过未知缺失连接曲线；精确文本和大整数极值继续保留。近期连续内存段之前由归档提供，之后使用原有内存
缩减，接缝在相同列上合并；内存中断、淘汰或整批跳过均可由归档补齐。无后台 Worker 的页面回退仍保留原有内存窗口限制。

配置、身份、观察起点及清空代次同时过滤内存和归档。冻结记录时间截点、归档字节截点，并复制每层尚会变化的末桶，后续
同时间戳样本也不会进入冻结视口。异步读盘前后检查 scope 配置和快照；清空、移除、重新配置或释放快照使旧请求取消。
“全部”、超采样裁剪和时间轴直接沿用全会话状态边界，P1 按每列时间自适应刷新规则继续限制跟随开销。

## 数据流与竞态

采样和写入共用连接及独占事务。批次仅包含按 4 字节对齐的 32 位项时，变量写入路径可保持目标运行。其余项在独立 OpenOCD 模式下需要目标暂停，托管调试运行时须先暂停调试。静态目标在特定窄写回读不匹配时可回退到较宽访问，动态窄写禁止扩大写入范围。写入验证、恢复状态和会话变化处理见[动态成员写入设计](dynamic-variable-writes.md#计划与执行)。

`liveStatus.canWrite/haltWrite` 在独立采样或暂停 DAP 就绪时为 `true/true`，托管调试运行期采样可用时为 `true/false`，禁止写入时为 `false/false`。托管调试运行态的普通写入和一次性读取受目标执行状态、调试会话与连接变化约束。只调整采样频率和观察列表，或停止连续采样及出现历史存储背压时，普通事务不会因此取消。动态卡片的请求还受有效采样和绑定约束。

采样 Worker 保持唯一连接与原有读取预算、写入互斥及会话代次。扩展宿主解码后分别写入磁盘归档和历史 Worker。Webview 只持有当前值、历史边界和当前视口的缩减分段；原始历史不会随采样时长累积到页面。

扩展宿主繁忙（其他扩展的 CMake 配置、同步解析等）时，采样时钟仍在 Worker 内按计划读取，样本带读取时刻的时间戳在 Worker 内排队，宿主确认后按分片补交，图表与归档时间轴不受交付延迟影响。积压预算为 16 MiB、4096 批或 30 秒，任一超出时丢弃最早的批次：同一代次连续丢弃的图表批次合成一个断点标记，按顺序先于后续样本送达，历史 Worker 在该处断开曲线（不标记 `limited`），每次繁忙期提示一次 `SAMPLING_HOST_BACKLOG`，采样不会暂停。磁盘归档队列达到 4 MiB 时只暂停向宿主交付（低于 1 MiB 才恢复），不关闭采样、不推进代次，因此已采到的样本在归档排空后照常写入；期间写入与 Agent 读取仍按原规则禁用。仍在宿主线程读取的暂停 DAP 采样维持原有的暂停与空行断点。计划和目标未变的暂停后恢复沿用已测得的读取耗时与自适应间隔，不再回到 100 ms 预热。速率提示中的 `Host stall`、`Backlog`、`Dropped` 分别是最近 1 秒内宿主事件循环最长阻塞、当前积压批数/时长和累计丢弃批数，用于区分宿主繁忙与探针变慢。

视口请求携带面板、会话 scope、清空代次、冻结编号、可见变量、时间范围、宽度及请求编号。非跟随时请求间隔至少 80 ms；跟随时按最近提交间隔与峰值抖动保留动态缓冲余量使显示时钟持续前推不断顿，明细刷新间隔降至 max(40 ms, 可见跨度 / 画布列数) 并拥有独立冷却计时（不受后台 1 秒一次粗略底图刷新冷却拖累），每窗口仍保留单一在途与单一待发请求。宿主批次聚合按 20 ms 触发、历史 Worker 状态防抖按 30 ms 发送，按像素列保留首尾、数值极值及精确整数极值，缺失点分段，并保留视口两端相邻点。异常断点过多使回复超过 262,144 点时明确提示缩小范围，不隐式连接缺失采样；失败的同一请求不会逐帧重发。

回复是否采用只取决于配置（清空代次、冻结编号、可见变量及其类型/地址/位域），与时间范围无关：拖动、滚轮缩放或拖动时间轴期间到达的回复照常采用，按其自身时间范围平移绘制；显隐、类型或地址变化、冻结切换或清空后的旧回复仍被丢弃。新配置的回复到达前，上一份数据中身份未变的曲线继续显示，避免闪空。

- 超采样：未跟随时按可见范围左右各多取一屏（截到保留边界），列数按可见部分保持画布宽度分辨率，上限 8192 列（超出时对称缩小超采样）。可见范围仍在已取范围内且分辨率在 1/3–1.5 倍之间时不发新请求；未跟随时仅数据版本变化的刷新最多每秒一次。
- 粗略底图：另以画布宽度（64–4096 列）请求整个保留范围，配置变化时立即请求，采样中最多每秒刷新；与明细请求共用在途名额，待发超过 1 秒时优先于明细发出。明细范围之外（拖出、缩小）用底图补画；跨过切口的底图段直接连到明细曲线自身的首尾点，底图点不会画进明细范围内，避免跟随时曲线左端随提交左右跳动。
- 跟随原子提交：跟随时状态事件只触发请求，不推进绘图边界；采用的明细回复同时提交其携带的边界与数据，最右端不再出现空白条。1 秒内没有采用的回复时退回事件边界。跟随请求向右多取 min(一屏, 5 s)。
- 传输：Worker 把回复按变量打包为 Float64 时间/数值列、Uint32 分段终点与稀疏精确文本（`src/webview/liveWatch/chartTransport.js`），以可转移 ArrayBuffer 发给扩展宿主；VS Code 对 Webview 消息中的类型化数组不做 JSON 序列化。Webview 解码后与原格式一致。
- 组合后的曲线数组在输入不变时复用同一实例，悬停重绘不重建绘图缓存。
- 平移绘图缓存使用相对坐标的 Float64 数组、原始点引用及 Uint32 包络索引，构建范围左右各多半屏；数据、归一化、画布/DPR、留白和 x/y 跨度不变且视口仍在构建范围内时，仅更新偏移。绘图只发出可见包络及两端相邻点，断点和精确整数标签保持原意。
- 自动纵轴以拟合目标跨度构建几何与抖动包络，动画通过纵向比例及偏移统一变换曲线、末端标记和命中坐标。每个连续段按 64 点缓存极值与计数。拖动时二分定位可见区间，用摘要汇总整块，仅扫描两端并求裁切线段的交点。
- 可见变量集合变化时清除极值缓存。原始数值模式下，自动纵轴在下一次绘制时立即适配当前可见曲线。
- 数据和视图不再变化、跟随时钟到达已提交边界且纵轴动画完成时跳过重绘。明细与底图请求按自己的节流期限调度，纵轴收缩等待到期后再绘制。实时跟随且当前明细已覆盖可见范围时，后台底图更新不重复合成与标脏重绘；所有数据仍在内存且未发生淘汰/裁剪时，`archiveViewport` 直接走内存快速路径。
- 采样中的固定跨度跟随窗口在未冻结、未拖动且未要求减少动态效果时，按本地经过时间平滑推进；显示时钟不倒退、不超过已提交明细的边界，停更后停在该边界。平滑跟随时下方时间轴以显示时钟为终点，选区与右端点保持贴在最右侧；拖动曲线、滚轮缩放、拖动时间轴选区或端点（含键盘）开始前，先把视图平移到已提交数据的边界再判断吸附与跟随，因此右端吸附后拖动左端点不会脱离吸附。“全部”仍按原子提交推进。自动 Y 轴与归一化复用每次明细提交计算的可见极值。实时自动适配随可见极值的中点平移，避免单向漂移在曲线一侧累积留白。显示范围在提交之间连续过渡，新提交的极值超出当前范围时立即纳入。动画帧仅在平均耗时乘 2 超过屏幕刷新间隔时才降帧（上限 80 ms），无固定 12 ms 跳帧下限；画布尺寸、主题样式与时间轴文本缓存复用以避免每帧回流，带抖动包络的末端标记落在平滑趋势线终点。可用 `node test/perf/layered-history-bench.js` 对比几何缓存与重建开销。

## 临时显示增益

侧栏、历史和新采样的曲线与悬浮值使用原值乘以增益；采样记录、冻结快照和 CSV 始终保留原始数值。变换发生在归一化之前，负数翻转归一化波形，零产生水平线，手动 Y 轴范围保持不变。

增益为 1 时保留原有精确整数和枚举显示；其他增益使用 JavaScript 数值乘积（超出精确整数范围可能舍入），不沿用原值文本或枚举名称。整数乘积遵循所选进制，小数使用十进制；乘积溢出显示为无读数并断开曲线。

每张图的增益独立保存在页面内存中，不写入工作区设置或 Webview 恢复状态。隐藏或切换标签页保留，移除变量（含父项）清除对应增益。
