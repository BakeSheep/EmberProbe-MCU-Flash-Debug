# 分层采样与静默历史

| 消费者                               | 目标频率            | 原始历史                            | 绘图                       |
| ------------------------------------ | ------------------- | ----------------------------------- | -------------------------- |
| 波形窗口观察变量（含已选择标量成员） | 用户设置 0.1–200 Hz | 最近 30 分钟内存历史 + 完整磁盘归档 | 仅计算可见曲线             |
| 波形窗口静默变量                     | 同上                | 同上                                | 重新开启时读取当前视口历史 |
| 仅侧栏观察或写入卡片                 | 固定 20 Hz          | 无                                  | 当前值                     |

全局启停保持原操作。改变波形目标频率不会改变侧栏独有变量的目标；两者同轮到期时合并读取，同名侧栏变量复用不足 50 ms 的原始结果。样本携带消费者归属和原始采集时间，侧栏额外读取不计入波形归档。探针负载高时两组受现有自适应降速限制。暂停调试目标后的 DAP 快照仍遵守至少 250 ms 间隔。

## 历史与导出

隐藏仅控制绘图，继续采样、记录及更新当前值（最多 20 Hz）。重新显示保持已有缩放与时间窗口；“全部”使用当前窗口全部观察变量的最近 30 分钟边界。移除变量停止采样，已记录数据仍能从完整归档导出。改观察类型重置该曲线的实时历史，完整归档按类型分别保留。

历史 Worker 每块保存 4096 点：Float64 时间、Float64 数值、Uint8 缺失标记，非 Number 等价的精确文本另存。按最新采集时间保留 30 分钟，每通道上限 360,001 点；降低采样率不删除窗口内的旧高频点。暂停期间不进行时间淘汰。`emberprobe.maxSamples` 已弃用且不覆盖用户配置值。

`emberprobe.chartHistoryMaxMiB` 默认 512 MiB，范围 64–4096 MiB。预算包含被冻结或导出引用保留的缓冲块，先释放过期块；仍不足时明确报错并暂停全局采样。失败批次不部分写入。释放快照、减少观察变量或调整预算后重新开始；恢复会从磁盘归档重建当前窗口、会话及清空代次的最近 30 分钟。磁盘归档容量及扩展退出清理策略保持原有配置；磁盘故障或容量耗尽也会暂停采样。

冻结通过引用固定后台历史范围，包含已有静默变量。采样与当前值继续更新，冻结后开启静默曲线查看冻结历史，新变量恢复实时后显示。清空取消待发当前值、视口请求和冻结快照，重置当前窗口/会话的归档代次；其他窗口不受影响。

导出来源：完整归档包含超过 30 分钟以及已移除变量的数据；实时保留数据与冻结快照由后台原始点生成，均包含静默变量，使用既有 CSV 转义及 64 MiB 输出限制。像素绘图数据不用于导出。Agent 的归档 CSV 请求接口保持原有方式；侧栏独有变量不再产生归档记录。

## 数据流与竞态

采样 Worker 保持唯一连接与原有读取预算、写入互斥及会话代次。扩展宿主解码后分别写入磁盘归档和历史 Worker。Webview 只持有当前值、历史边界和当前视口的缩减分段；原始历史不会随采样时长累积到页面。

视口请求携带面板、会话 scope、清空代次、冻结编号、可见变量、时间范围、宽度及请求编号。正常请求间隔至少 80 ms，每窗口一个在途及一个最新待处理请求。显隐、拖动、缩放或清空后的旧回复不得覆盖新视图。按像素列保留首尾、数值极值及精确整数极值，缺失点分段，并保留视口两端相邻点。异常断点过多使回复超过 262,144 点时明确提示缩小范围，不隐式连接缺失采样。
