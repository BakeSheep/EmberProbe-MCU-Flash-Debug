# Agent 配置与操作权限

侧栏“Agent 配置”卡片与“MCU 配置”并列，分别保存折叠状态。展开后包含 Agent Skills 安装开关、
MCP 服务器安装入口和“完全允许 Agent 操作”开关。

完全允许开关默认关闭，权限仅保存在当前 VS Code 工作区状态中。开启时同时启用 Agent 访问通道；
关闭后取消后续操作的全权授权，保留正常的 Agent 连接与已有的单独授权。已开始的操作不会自动取消。
没有打开受信任工作区时无法开启，Agent 不能通过 Bridge 或配置 API 自行开启。

全权授权适用于烧录、Flash 校验、变量写入、外设写入以及 CubeMX/CubeMX2 生成，适用时返回
`mode: "full"`，无需操作确认 ID。MCP 与技能脚本使用相同的授权结果。

该授权只免除操作确认，仍执行探针独占、目标/连接身份、ELF 和 SVD 输入、文件路径、会话/停止代次、
外设副作用与写后回读等检查。匿名探针的 Flash 和变量写入继续使用单次确认；ELF 与已烧录固件不匹配时，
变量写入仍要求确认。MCP 客户端自身的工具审批和修改过的技能内容审批由各自机制管理。

权限按钮等待扩展主机保存后才显示新状态；保存失败会显示错误并保留主机确认的状态。重新打开页面时，
权限从主机读取，不从 Webview 缓存恢复。

软件测试使用模拟目标，不执行实板烧录、写入或代码生成。信任边界详见
[AGENT-TRUST-BOUNDARIES.md](AGENT-TRUST-BOUNDARIES.md)。
