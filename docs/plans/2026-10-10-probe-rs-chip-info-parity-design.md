# probe-rs 芯片信息对齐

目标：补齐 OpenOCD 芯片面板已有的身份、厂商线索、状态、停机寄存器和执行控制，保留现有硬件授权、探针租约和会话代次边界。

## 实现选择

普通独立读取保留 `probe-rs read`，避免 DAP attach 的主动暂停。其余选择包括全部改为 DAP（会改变运行中的目标状态），或直接写核心调试寄存器进行控制（会自行承担寄存器控制协议）；采用只读 CLI 加受限短连接 DAP，复用已验证的适配器传输和进程退出逻辑。

- `probeRsChipInfo.js` 将 probe-rs 芯片名映射到共用 STM32 地址表，按自然宽度读取，并共享 CPUID、JEP106、IDCODE、UID 解码。ROM 的三段连续数据合并读取，CLI 解析支持多行输出。
- 未知系列不扫描其他家族地址；H7R/S 不复用旧 H7 地址。APM32F4/Geehy 指纹的 UID/容量仍保持限制。修正共用规则中 H72x Device ID `0x483` 的家族映射。
- 独立模式从 DHCSR 读取运行/停机状态，只有确认停机时才用短连接 DAP 读取 `info reg`。活动调试会话复用其 DAP，按所选 session 和停止代次验证每次请求。
- `probeRsChipSession.js` 借用外层 `chipInfo` 租约，启动现有 stdio 适配器，不加载固件、不发送 `configurationDone`。断开不要求暂停或终止目标。清理失败保留租约，由晚到的进程 close 事件释放。
- 侧栏 Pause/Run/Reset 在当前连接上执行。独立控制复核状态、使用短连接并读回验证；活动会话使用 DebugSessionBridge 的状态确认。缓存连接变化、写入、执行切换或其他探针占用时拒绝操作。
- 芯片关键信息读取失败报错；选填字段失败保留其他结果，并在面板和 Agent `readErrors` 中提供诊断。读取限制为每次至多 128 字节、累计至多 256 字节、15 秒；寄存器响应至多 8192 字符。
- 电压和探针固件/硬件版本缺少通用上游查询，保持未知。链路速度是配置值，探针类型只在选择器可确定时推断。

## 验证

1. 扩充 `test/probe-rs-chip-info.test.js`：已知家族、F4/F7 半字地址、ROM 多行输出、厂商线索、未知目标限制、部分失败、输入和时间预算。
2. 新增 `test/probe-rs-chip-session.test.js`：停机读取不 resume、显式控制及状态回读、初始化/请求失败、退出未确认与晚到 close 的租约行为，注册至普通测试组。
3. 扩充 `test/probe-rs-safety.test.js` 和 `test/backend-routing.test.js`：选定会话控制、写入冲突、缓存过期、连接变化和租约释放。
4. 扩充侧栏 DOM 测试和 `test/e2e/suite/probe-rs.test.js`：身份字段、PC/SP/LR、三个执行动作、能力按钮和错误提示。
5. 执行 `npm run check`、`npm run quality`、`npm run bundle`、`npm run test:e2e`，检查文档和 diff。只运行模拟探针与软件回归；实板、HIL、驱动切换和烧录未获授权。

## 读取性能优化

用户提供 F407_car 工程，并选择保留当前独立连接方式、优先减少运行干扰。普通运行态读取继续使用 CLI，不引入额外 DAP 初始化暂停，不使用可能跨实际芯片失效的身份缓存。

- 面板在 CPUID 返回后显示阶段结果，完成前不显示可用控制按钮；最终结果完成后才更新完整缓存。
- 将 Agent 字段/分组传入读取计划；ROM 指纹仍作为 UID/容量的必要校验，核心架构检查和原读取预算保留。选择性读取不覆盖完整面板缓存。
- F1/F2/F4 两个工厂字段跨度为 20 字节，F7 为 36 字节，合并半字读取，读取失败退回分字段；其他系列、Geehy 限制和未知地址行为不变。
- 显式控制后的信息刷新在同一持租约 DAP 内完成，省去关闭、CLI 重连和再次 attach，并沿用控制事务的期限。
- 通过只读实板测量首字段/分组耗时；控制、复位、烧录和完整 HIL 不在此次验证范围。补充路由、缓存、字段依赖、合并失败回退、进度与连接次数回归测试，运行完整软件检查。
