# 写入滑条连续调节设计

## 目标

- 拖动写入滑条时连续更新 MCU 变量，但将写入频率限制为最多 10 Hz。
- 松开滑条时立即写入最终值，避免节流留下中间值。
- 输入框提交超出当前滑条端点的值时，保持区间跨度和滑块原有相对位置不变，整体平移左右端点。
- 将写入结果提示点放在变量名前面。

## 数据流

滑条的 `input` 事件更新本地显示，并通过按变量隔离的 100ms 节流器发送写入。第一次拖动立即发送；持续拖动期间保留最新值并在下一个节流时刻发送；`change` 事件取消待发送任务并立即发送最终值。

输入框提交值前记录当前区间与当前滑块位置。只有新值越过端点时才平移区间：新区间跨度等于旧跨度，新值在新区间中的比例等于旧值在旧区间中的比例。区间内输入沿用原端点。

## 验证

- 单元测试覆盖区间上移、下移、区间内不变和滑块比例保持。
- Webview 结构断言覆盖 100ms 节流、最终立即写入及提示点位于变量名前。
- 运行完整项目检查，确认语法、静态检查和既有行为未回归。
