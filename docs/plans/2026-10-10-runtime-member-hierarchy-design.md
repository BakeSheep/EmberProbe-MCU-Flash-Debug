# 实时变量卡片成员层级设计

图表窗口和侧栏的实时复合变量卡片应与静态布局卡片保持一致：具名结构、类、联合体和数组成员可以逐层展开，数组元素显示索引。ELF 全部变量与导入选择器继续展示平铺的完整成员路径。

运行时采样树已保留嵌套关系；问题发生在两个卡片渲染器递归时重复使用父容器。复用现有嵌套分组的样式和展开状态存储，将每个具名复合成员渲染至自己的子容器。匿名成员仍提升到父层，与静态布局一致。

叶子的完整路径、采样地址和类型保持原有身份。只有结构变化时重建 DOM；数值刷新复用现有节点，结构变化后按完整路径恢复展开状态。子树不可用的提示保留在对应分组内。

验证覆盖两种卡片、多层同名成员、结构数组、标量数组、匿名成员、展开状态持久化、采样更新及地址变化后的曲线选择。另运行现有平铺选择器回归和项目要求的 check、quality、bundle、Extension Host 测试；此次验证不操作硬件。
