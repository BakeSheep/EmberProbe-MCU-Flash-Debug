# 采样帧率预设滑条

波形工具栏显示“采样帧率”，将原有“不限速”按钮合并到输入框内下拉按钮打开的滑条。

- 输入框保留 0.1–200 Hz 手动输入。下拉面板只包含滑条，无额外可见说明。
- 预设为 20、50、100、200 Hz；实验性设置开启后追加不限速挡位。
- 挡位以短竖线表示，轨道、面板与滑块均使用圆角矩形。滑条支持拖动、点击及方向键。
- 选到不限速时，输入框显示 `-`，紫色渐变从轨道右侧向左铺开；系统要求减少动态效果时取消过渡。
- 拖动超过相邻挡位的中点后才切换；滑块与色条使用相同的离散位置和缓动，输入框即时预览。`Hz` 在输入框边框外。
  拖动期间不提交配置，结束时才发送一次现有 `setFrequency` / `setUnlimitedSampling` 消息；取消则恢复原值。
  后台遥测和配置回执不打断正在进行的拖动。键盘仍逐挡切换。
- 不限速直接绘制柔和融合的蓝紫渐变，按径向距离产生从右端内侧中心扩散的圆形波纹。
  扩散边缘柔化，宽幅光晕缓慢流动，避免密集色块和强烈明暗条纹，不使用粒子或散点。
  仅在面板可见时绘制，限制为 30 FPS、384×64 像素。
  系统要求减少动态效果时只绘制一次静态画面。
  `-` 仅用于显示，后台的有限目标帧率仍保持有效，保留调试会话回退及实验性功能门控。
- 下拉按钮和 Alt+下打开滑条；Escape、点击外部或焦点移出关闭。关闭后 Escape 将焦点还给下拉按钮。
- 覆盖预设切换、输入校验、功能开启/撤销、调试抑制、开始采样、语言切换及焦点行为。

本地 mockup 使用 `/?unlimited=1` 显示第五挡，模拟宿主仅回显模式，不改变模拟采样计时器。
验证包括真实浏览器中的深浅主题及窄屏布局，仓库 `check`、`quality`、`bundle` 和 E2E。
