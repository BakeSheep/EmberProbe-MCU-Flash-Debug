# 波形页响应式 UI

目标：减少诊断信息和工具栏占用的空间，让窄波形页仍能同时查看变量和曲线。

实现与验收：

1. 共享 ELF 诊断渲染器使用原生 `details` / `summary`，默认只显示标题。
   用户展开后，同一批诊断刷新或切换语言保留展开状态；诊断清空后再次出现时默认折叠。
   侧栏、波形页和导入窗口复用该行为，详情内容独立滚动。
2. 删除搜索旁的“添加”按钮，保留搜索候选点击、方向键选择和 Enter 添加。
   搜索框与采样按钮、导入按钮组成弹性工具组；频率和历史操作在空间不足时换行。
3. 波形页不超过 760px 时上下布局，560–760px 显示两列变量卡片，低于 560px 显示一列。
   双列按变量顺序交替分配到两个独立的纵向容器；树状卡片展开只推动本列后续卡片，另一列保持紧凑。
   切回单列时按原始变量顺序重新排列现有 DOM 节点，保留展开状态、事件绑定、键盘焦点和滚动位置。
   卡片保留长名称截断、复合成员展开和独立的移除按钮。
4. 上下布局中显示横向分隔条，支持鼠标或触摸拖动及上下方向键调节变量区高度。
   高度独立保存到 Webview 状态，左右布局仍保留原来的宽度；限制拖动范围，为图表预留空间。
   宽度和高度分别恢复，容器变小时由 CSS 限制实际高度。
5. 覆盖折叠状态、搜索入口、双向分隔条、上下限、取消拖动、持久化及语言更新；
   使用 mockup 验证中英文、宽窄布局及图表区域，并执行仓库要求的检查。

相关文件：`src/liveWatchView.js`、`src/webview/runtime.js`、
`src/webview/liveWatch/{renderer.js,app.css}`、`src/webview/sidebar/app.css`、`src/i18n/{en,zh}.js`。

验证不连接硬件，不建立真实采样会话。
